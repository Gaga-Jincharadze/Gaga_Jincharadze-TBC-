# Bank Customer Churn Prediction Project

## Overview

პროექტი მოიცავს ბანკის მომხმარებლების გადინების პროგნოზირებას. გადინება გულისხმობს კლიენტების მიერ კომპანიის მომსახურებაზე ან პროდუქციაზე უარის თქმას. ამისთვის კი ვიყენებ ML ალოგრითმს, როგორიც არის
logistic regression. დამატებით, ამისა გამოყენებული მაქვს მონაცემთა ვიზუალიზაციისთვის სხვადასხვა ტიპის
chart/გრაფიკი და მცირე სტატისტიკური ანალიზი.

## Features

1. **Churn Prediction**: პროგნოზირებს კლიენტი დატოვებს თუ არა კომპანიას და უზრუნველყოფს გადინების ალბათობებს თითოეული კლიენტისთვის.

2. **Data Visualization**:

- ასაკობრივი განაწილების გრაფიკი.
- კლიენტების გადინების ანალიზი სქესის მიხედვით.
- რიცხობრივ ცვლადებს შორის კორელაციის თბური რუკა.

3. **Salary Analysis**: გამოითვლის ხელფასების საშუალო, მინიმალურ, მაქსიმალურ, მედიანურ მაჩვენებლებს და სტანდარტულ გადახრას სქესის მიხედვით დაჯგუფებით.

## File Structure

- **`age_distribution.py`**:
- ქმნის ჰისტოგრამას მონაცემთა ნაკრებში ასაკობრივი განაწილების ვიზუალიზაციისთვის.
- **`churn_by_gender.py`**:
  - ვიზუალიზაციას უკეთებს მომხმარებელთა გადინებას სქესის მიხედვით.
- **`correlation.py`**:
  - აგენერირებს heatmap chart-ს, რომელიც აჩვენებს კორელაციას რიცხვით ცვლადებს შორის.
- **`salary.py`**:
  - ითვლის ხელფასის სტატისტიკას სქესის მიხედვით დაჯგუფებულად.
- **`churn_prediction.py`**:
  - იყენებს logistic regression- ს მომხმარებელთა გადინების პროგნოზირებისთვის და აგენერირებს პროგნოზების CSV ფაილს.
- **`Bank Customer Churn Prediction.csv`**:
  - მონაცემები, რომელიც გამოყენებული იქნა მოდელის ასაგებად.
- **`customers_with_churn_predictions.csv`**:
  - შეიცავს მომხმარებლის ID-ებს, პროგნოზირებულ კლასებს ( 1 ან 0 ) და გადინების ალბათობებს ( 0 - 100).

## Dataset

ფაილი შედგება შემდეგი სვეტებისგან/ინფორმაციისგან:

- **`id`**: მომხმარებლის უნიკალური ამომცნობი კოდი, რომელიც ბანკმა მიანიჭა
- **`gender`**: სქესი
- **`age`**: ასაკი
- **`balance`**: ბალანსი
- **`products_number`**: ბანკის რამდენ პროდუქტს ფლობს
- **`churn`**: შეწყვეტილიაქვს თუ არა ბანკის მოხმარება. 1 - კი , 0 - არა.
- **`tenure`**: რამდენი წელია, რაც იყენებს ბანკის პროდუქტებს/მომსახურებას.

## How It Works

1. **Data Preprocessing**:

- კატეგორიული ცვლადების (მაგ., `gender`, `country`) რიცხვით მნიშვნელობებად კოდირება `LabelEncoder`-ის გამოყენებით.
- რიცხვითი მნიშვნელობის მქონე ცვლადების სკალირება, რათა ერთ ჩარჩოში მოვაქციოთ `StandardScaler`-ის გამოყენებით.

2. **Logistic Regression Model**:
   - მონაცემთა ბაზის 80%-ზე (X_train, y_train) ხდება მოდელის გაწვრთნა
   - მონაცემთა ბაზის 20%-ზე (X_test, y_test) ხდება მოდელის ტესტირება.
   - Outputs: accuracy, confusion matrix, და classification report.
3. **Churn Prediction**:
   - ითვლის მომხმარებლის წასვლის ალბათობას.
   - ალაგებს მომხმარებლებს მათი წასვლის ალბათობის მიხედვით.
